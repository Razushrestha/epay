# §16 Deliverables and acceptance

## 16.1 Deliverables

- Storefront + admin on **client servers**
- Full **source** in client repo + deploy scripts
- DB schema, ER diagrams, migrations
- OpenAPI + architecture documentation
- Admin manual; buyer/seller guides
- Training ≤4 hours; **30 days** post-launch defect support

## 16.2 Acceptance criteria

- Every **Included** §4 feature works on staging at milestone demo
- No open **critical/high** defects at go-live
- Performance §10.3 met on production-sized load test
- Automated tests pass for bidding, ledger, checkout
