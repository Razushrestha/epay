# §4.1 User and account management

| Feature | Details | Release |
|---------|---------|---------|
| Registration and login | Email or phone + password; OTP verification; Google sign-in | **Included** |
| Two-factor authentication | OTP or authenticator; mandatory for **staff** and **sellers** | **Included** |
| Password recovery and sessions | Reset via email/OTP; list and revoke devices | **Included** |
| Roles and account types | Buyer+seller one account; individual or business | **Included** |
| Profile and address book | Personal/business profile; multiple addresses; defaults | **Included** |
| Seller KYC | ID + address proof upload; admin approve/reject with reason | **Included** |
| Feedback score and seller levels | Pos/neu/neg counts; new → standard → above standard → top rated | **Included** |
| Restriction, suspension, appeals | Admin actions with reason, duration, appeal workflow | **Included** |

**M1 tasks:** auth API, profiles, addresses, KYC workflow, basic seller level fields.
