# §18 Risks and assumptions

| Risk | Mitigation |
|------|------------|
| “Exactly like eBay” scope creep | Fixed §4 Included list; Phase 2 / change requests |
| Gateway approval delays | Start week 1; sandbox + mock gateway |
| Escrow regulation | Client confirms early; escrow can be disabled |
| Servers late | §17 dates; staging from week 2 |
| Auction-end load | Locks + concurrency + load tests before go-live |
| Late feedback / changing requirements | Weekly call, biweekly demo, written CRs |
